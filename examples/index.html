Examples

Six demos, no build step

Each one is a few dozen lines of plain ES modules, served exactly as written.

auril.js is a no-build frontend kernel for personal apps: escaped html`` templates, DOM morphing, custom elements, one store, a Navigation-API router — 504 lines you own. This popover needs no JS at all: popovertarget is enough.
  • Start here Todos The canonical app: CRUD, inline editing, filters, search-as-you-type, persistence — every kernel piece.
  • Smallest Counter The smallest possible app: one store, one component, persisted across reloads.
  • Async Async search Loading / error / retry states, request cancellation, and the api.js seam — all component-local state.
  • Navigation API Router Navigation-API routing with params, deep links, back/forward, and view transitions between views.
  • View Transitions Animation List shuffle/sort/add/remove animated by View Transitions — CSS pairs the cards, morph moves them.
  • Stress test DBMonster The classic repaint stress test: full table re-render + morph every animation frame, with FPS counter. Deliberately far over the ~250-node per-component ceiling — a measurement, not a pattern to copy.

Add ?auril-dev to any demo URL for debug logging. Source on GitHub.
