auril.js examples

Each demo is a few dozen lines of plain ES modules — no build step.

auril.js is a no-build frontend kernel for personal apps: escaped html`` templates, DOM morphing, custom elements, one store, a Navigation-API router — 430 lines you own. This popover needs no JS at all: popovertarget is enough.
  • Todos The canonical app: CRUD, inline editing, filters, search-as-you-type, persistence — every kernel piece.
  • Counter The smallest possible app: one store, one component, persisted across reloads.
  • Async search Loading / error / retry states, request cancellation, and the api.js seam — all component-local state.
  • Router Navigation-API routing with params, deep links, back/forward, and view transitions between views.
  • Animation List shuffle/sort/add/remove animated by View Transitions — CSS pairs the cards, morph moves them.
  • DBMonster The classic repaint stress test: full table re-render + morph every animation frame, with FPS counter.
